# Templates per Sector

Cada fitxer `{SECTOR}.md` conté tres blocs:

1. **Prospecting** — Missatges per a captació de clients (email/whatsapp)
2. **Meta Ads** — Estructura de campanya + creativitats
3. **Agent IA** — Prompt base per a l'assistent virtual (el que utilitza el sistema)

## Com usar-ho

1. Obre el fitxer del sector que necessitis
2. Substitueix les variables `{NOM_NEGOCI}`, `{CIUTAT}`, etc. per les dades del client
3. Rebecca: ajusta el to, els preus i els serveis segons el client concret

## Placeholders

| Variable | Què posar |
|----------|-----------|
| `{NOM_NEGOCI}` | Nom del negoci |
| `{CIUTAT}` | Ciutat o població |
| `{SERVEIS}` | Llista de serveis principals |
| `{PREU_DESDE}` | Preu mínim orientatiu |
| `{RADI}` | Radi de cobertura (ex: 15km) |
| `{EDAT_MIN}` | Edat mínima del públic objectiu |
| `{EDAT_MAX}` | Edat màxima del públic objectiu |
