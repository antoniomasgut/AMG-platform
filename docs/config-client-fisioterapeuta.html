01AMG Crear el tenant al portal~5 min
Portal: Admin → Tenants → Nou tenant. Camps: nom del negoci, email, telèfon, sector = FISIOTERAPEUTA, mida = AUTONOMO. El sistema assigna un UUID automàticament i crea la base de coneixement (KB) buida. Guarda l'ID del tenant per als passos posteriors.
02Client Configurar WhatsApp Business API~30 min
Requisit previ: el número de telèfon NO pot tenir WhatsApp instal·lat al mòbil (Meta l'exclou si el detecta). Opcions:
· Opció A — número actual del centre: el client desinstal·la WA del mòbil → fem la verificació (perd WA personal ~5 min) → torna a instal·lar WA personal amb un altre número.
· Opció B (recomanada): SIM nova de Yoigo, Más Móvil o OMV. Cost: ~6€/mes amb 50 SMS. Mantenim control total.
Procés: Meta Business Manager → Configura → WhatsApp → Afegir número → Verificació per SMS o trucada → Enviar nom d'empresa per aprovació Meta. Temps: 24–72h.
03Client Crear el bot de Telegram i vincular el propietari~10 min
Pas 1 — Crear el bot (fa AMG, ~5 min): Obre Telegram → busca @BotFather → escriu /newbot → tria un nom (ex: "Clínica López Fisio") i un username que acabi en _bot (ex: clinicalopezfisio_bot). @BotFather retornarà un token del tipus 1234567890:ABCdefGHIjkl... — copiar-lo.
Pas 2 — Registrar el bot al portal: Portal: Admin → Tenants → [id del tenant] → scroll fins a "Telegram Bot" → "Configurar bot" → enganxar el token → "Desar i registrar webhook". El sistema connecta automàticament i mostra l'estat "Connectat" i el link t.me/[nombot]. Si falla, usar "Re-registrar webhook".
Pas 3 — Vincular el propietari per a les alertes: Al portal del tenant (no admin): Agents → Canals → Telegram → botó "Obrir bot de Telegram →". Copiar l'URL i enviar-la al fisio per WhatsApp. El fisio l'obre a Telegram i escriu qualsevol missatge (o /start). El bot confirmarà la vinculació. A partir d'aquí rebrà alertes de leads nous, cites reservades i incidències.
Nota: si el bot demana un codi d'enllaç, contactar AMG per generar-lo manualment. El grup Telegram compartit (fisio + AMG) és opcional però recomanat per detectar incidències junts.
04AMG Crear la Landing Pro~20 min
Material que cal tenir del client: foto professional del fisio o del centre (mín. 1200px ample), llista de serveis + preus + durades, horaris, adreça, i 2–3 testimonis de pacients si en té.
Seccions de la landing: Hero (foto gran + CTA "Reserva ara"), Serveis (targetes amb preu), Sobre mi (breu bio), Ressenyes Google (widget automàtic), Contacte (formulari RGPD + mapa).
Chat widget: un cop activat l'agent IA, afegir el codi del widget a la landing des de Portal → Landing → Widget → Copiar codi HTML.
05AMG Activar l'Agent IA i configurar la base de coneixement~30 min
Portal: Tenant → Setup → Agent IA → Activar. Un cop actiu, anar a Tenant → IA → Base de coneixement i afegir la informació del centre.
Contingut mínim de la KB: llista de serveis + preus, horaris d'atenció, adreça + com arribar-hi, política de cancel·lació, resposta a "accepteu mútua X?" (important!), i FAQ habituals.
To de l'agent: professional però proper. Ex: "Hola! Soc l'assistent virtual de [NOM CENTRE]. Puc informar-te de serveis, preus i horaris, o ajudar-te a demanar cita 😊". Personalitzar el nom si el client ho prefereix.
06AMG Activar l'Agenda digital~15 min
Portal: Tenant → Setup → Agenda → Activar → mode: appointment.
Configurar: durada de sessió (45 min habitual), buffer (15 min per canviar llençol), horaris per dia de la setmana, recordatoris (activar 24h + 2h).
Google Calendar: Portal → Tenant → Integracions → Google → Autoritzar. El client inicia sessió amb el seu Google. L'agent consultarà el calendar en temps real per saber quins slots estan lliures i crearà events automàticament quan es reserva una cita.
07AMG Activar la Fidelització~10 min
Portal: Tenant → Setup → Fidelització → Activar.
URL de ressenyes Google: el client ha d'entrar a Google Business Profile → clicar "Compartir perfil" → copiar l'URL específica de ressenya (comença per g.page/r/...). Si no té perfil de Google My Business, cal crear-lo primer — la verificació pot trigar 3–7 dies per carta o trucada de Google.
Configurar dies de follow-up (7 dies recomanat per fisio) i el missatge post-sessió.
08AMG Configurar SMTP Corporatiu (si contractat)~15 min
Necessari si s'activen els pressupostos digitals o si el fisio vol enviar emails amb la seva adreça professional.
Procés via Brevo (gratuït fins 300 emails/dia): Crear compte a Brevo → Senders & IP → Configurar un domini → Afegir els registres TXT/DKIM al DNS del domini (Namecheap, GoDaddy, etc.) → Clicar Verificar. Temps: 5 min + propagació DNS (1–24h).
Resultat: els emails sortiran com info@[domini-del-fisio].com en lloc d'un genèric.
09AMG Prova funcional: pacient nou per WhatsApp~10 min
Enviar un WhatsApp al número del centre simulant un pacient nou: "Hola, voldria demanar cita per un dolor lumbar. Quan podeu atendre'm?"
Verificar que: (1) l'agent respon en menys de 30 segons, (2) informa serveis i preus correctament, (3) proposa slots disponibles de l'agenda, (4) quan es confirma la cita, apareix al portal i al Google Calendar del fisio, (5) el fisio rep notificació per Telegram amb les dades del pacient.
Si algun punt falla, revisar la configuració de la KB o de l'agenda.
10AMG Verificar recordatoris de cita~5 min
Portal: Tenant → Agenda → Cites. Veure la cita de prova i comprovar que apareix "Recordatori pendent" per 24h i 2h.
Per provar en temps real sense esperar 24h: crear una cita manual per d'aquí 30 min i verificar que arriba el recordatori. Si no arriba, comprovar que el número de WhatsApp del pacient és correcte i que el servei d'enviament està actiu.

· Landing: com enviar l'URL als pacients actuals per compartir-la i demanar ressenyes.
