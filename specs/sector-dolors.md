# Dolors per sector — NexeLocal

Diagnòstic comercial per sector. Quan s'identifiquen els dolors d'un client, el sistema pot generar automàticament una proposta amb les fases recomanades i un missatge en llenguatge de negoci.

**Fases del sistema:**
- F1 — Captació (leads, agent IA, resposta immediata 24/7)
- F2 — Agenda (cites, Google Calendar)
- F3 — Pressupostos (quotes, facturació, cobros)
- F4 — Seguiment / Fidelització (analytics, reactivació)
- F5 — Alertes & Equip (organització interna, notificacions)

---

## FISIOTERAPEUTA / Osteopata

**Sector key:** `FISIOTERAPEUTA`

### Dolors habituals
- Trucades perdudes
- Cites oblidades (no-shows)
- Pacients que no tornen
- Poc temps administratiu

### Fases prioritàries
- ✅ F1 — Captació i resposta immediata
- ✅ F2 — Cites i planificació

### Fases recomanades
- ⭐ F4 — Fidelització
- ⭐ F3 — Seguiment comercial

### Missatge de venda
> Reduïm les absències, millorem la gestió de cites i ajudem a que els pacients tornin amb més freqüència.

## Notes d'implementació

### Sectors pendents d'afegir al backend (`SECTORS` a `admin.ts`)
```
DENTISTA, REFORMES, ADVOCAT, ENTRENADOR
```

### Ús recomanat
1. **Wizard de configuració** (`/wizard`) — mostrar dolors rellevants al pas de selecció de fases
2. **Prospecció** (`/portal/prospecting`) — filtrar per sector i mostrar el missatge de venda
3. **Proposta automàtica** — futura funcionalitat: marcar dolors detectats → generar PDF de proposta
4. **Onboarding comercial** — quan un admin crea un tenant nou, el sistema suggereix fases basant-se en el sector

### Lògica de priorització
- **Fases prioritàries** → aparèixer pre-seleccionades al wizard
- **Fases recomanades** → aparèixer com a suggeriment secundari
- Si un sector té F2 prioritària → activar camp "Calendar ID" obligatori al wizard
- Si un sector té F3 prioritària → activar camp "Moneda i IVA" al wizard
