1. Resum Executiu

AMG Digitalització és una plataforma SaaS multi-tenant dissenyada per gestionar webs, automatitzacions i la presència digital de negocis locals, principalment a Mallorca. El projecte es troba en un estat altament avançat de desenvolupament, amb el backend quasi complet (36 mòduls especificats, 85+ entitats JPA, 47 controladors REST, 60+ serveis) i un frontend complet amb 50+ rutes, 61 components i plena internacionalització (4 idiomes).

694 Fitxers Java (main)
36 Mòduls especificats
85+ Entitats JPA
47 Controladors REST
50+ Rutes frontend
4 Idiomes (ca/es/en/de)

La plataforma utilitza un model de negoci de fases NexeLocal (F1-F5) que permet als negocis locals contractar serveis digitals progressius: captació de clients, agenda online, pressupostos, seguiment, i alertes d'equip. A més, ofereix landings, dominis, hosting web, chatbots IA, i integració amb WhatsApp Business, Telegram i email.

2.3 Principis arquitectònics

  • Arquitectura hexagonal — cada mòdul segueix la jerarquia api/ → application/ → domain/
  • Multi-tenant — totes les entitats tenen tenant_id (separació lògica per schema PostgreSQL)
  • RBAC — 3 rols: SUPER_ADMIN, ADMIN, CLIENT
  • Provider pattern — cada servei extern (Stripe, Holded, GoCardless, n8n, GCS, prospecting) té un provider amb implementació mock per defecte
  • JWT stateless — autenticació via access token (15 min) + refresh token (7 dies)
  • i18n first — 4 idiomes amb next-intl i locale prefix sempre visible

9. Seguretat

9.1 Autenticació i Autorització

  • JWT amb HMAC-SHA, signatura amb secret configurable via JWT_SECRET
  • Access token: 15 minuts de vida
  • Refresh token: 7 dies (UUID, emmagatzemat a PostgreSQL)
  • 3 rols: SUPER_ADMIN, ADMIN, CLIENT
  • Bloqueig després de 3 intents fallits (15 min)
  • Rate limiting per email (5/15min) i IP (20/15min) via Redis

9.2 Xifratge

  • Credencials xifrades amb AES-256-GCM (Jasypt)
  • Contrasenyes amb BCrypt (strength 12)
  • JWT signat amb HMAC-SHA

9.3 Seguretat web (frontend)

  • Content Security Policy amb nonce per scripts
  • X-Frame-Options: DENY
  • X-Content-Type-Options: nosniff
  • HSTS (1 any, includeSubDomains)
  • Permissions-Policy restrictiva
  • Strict CSP amb 'strict-dynamic'

9.4 Seguretat de xarxa (infra)

  • Traefik amb SSL Let's Encrypt (TLS challenge)
  • Xarxa interna Docker (amg_net) — aïllament de serveis
  • Rate limiting global: 100 peticions/min
  • HSTS amb preload
  • Basic Auth per dashboards sensibles (Traefik, Netdata)

11. Conclusions i Recomanacions

Punts forts ✅

  • Cobertura funcional molt àmplia — 36 mòduls especificats, quasi tots implementats
  • Arquitectura hexagonal neta — separació clara en api/application/domain per cada mòdul
  • Provider pattern — tots els serveis externs tenen mode mock, facilitant testing i desenvolupament offline
  • Internacionalització completa — 4 idiomes amb next-intl, locale prefix, i SEO multilingüe
  • Seguretat sòlida — JWT, CSP, rate limiting, AES-256, BCrypt, HSTS
  • Infraestructura ben definida — Docker Compose, Traefik, Terraform, alertes Telegram
  • Kits operatius — 10 kits que permeten escalar el negoci amb tasques especialitzades
  • Model de negoci clar — fases NexeLocal F1-F5 amb preus i serveis ben definits

Punts a millorar 🔧

  • Cobertura de tests backend baixa — només 19 fitxers de test per 694 fitxers de codi (2.7%)
  • CI/CD incomplet — no hi ha desplegament automàtic a producció
  • Monòlit Maven — tot el backend en un sol mòdul, idealment caldria modularitzar
  • Spec 26 (RAG Knowledge Base) — en estat "en curs", pendent de completar
  • No hi ha README.md — el projecte no té una documentació d'entrada al repositori
  • Missatges i18n duplicats — els fitxers de traducció existeixen tant a messages/ com a src/messages/
  • Sense monitoratge d'errors — no s'ha detectat integració amb Sentry, Datadog o similar
  • Documentació API — no s'ha trobat OpenAPI/Swagger UI
